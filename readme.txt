STILL NEEDED ON YOUR PLATFORM
- Review the privacy and cookie information for the Cal.com embed before launch. Keep add a site consent banner if you introduce other non-essential cookies.
- Ideally a form service (Formspree, Netlify Forms) so requests reach you without the visitor's email app

UPLOADING (pick one)
- Netlify: go to app.netlify.com/drop and drag the whole "website" folder in. Add your domain under Domain settings.
- Cloudflare Pages / GitHub Pages: upload both files to a new project or repository; index.html must sit at the top level.
- Traditional hosting (cPanel, IONOS, etc.): upload both files into the public_html folder using File Manager or FTP.
- WordPress: use a plugin that allows custom HTML pages, or rebuild sections in the editor and copy the text over.
- Squarespace / Wix: these do not accept raw HTML file uploads. Copy the text into their editor, or embed the code in a Code/Embed block.

After upload, open the site on your phone, test the form, the WhatsApp button and the footer links in both languages.
